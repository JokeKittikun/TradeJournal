ใช้งานประจำวัน พอร์ต กราฟ บันทึกไม้ ประวัติการเทรด สรุปผล อื่น ๆ

Trade Journal ทำอะไรได้บ้าง

บันทึกเทรด BTC Futures ตามกรอบราคาช่วงตลาด US เปิด (M30 H1) พร้อมกราฟสด คำนวณ TP / SL / Leverage ให้อัตโนมัติ และเก็บข้อมูลไว้ในบัญชีของคุณ เปิดจากเครื่องไหนก็เห็นเหมือนกัน

ข้อมูลอยู่ในบัญชีของคุณ ราคาจาก Binance / MEXC ใช้ได้ทั้ง คอม · iPad · มือถือ

ใช้งานประจำวัน

ลำดับที่ใช้บ่อยที่สุดในหนึ่งวันเทรด

  1. เลือกพอร์ต ที่หน้า "พอร์ต" (หรือกดชื่อพอร์ตที่หัวเว็บเพื่อสลับเร็ว)
  2. รอกรอบก่อตัว ช่วง 20:30–21:30 น. ตาราง "กรอบราคาจากตลาด" นับถอยหลังและอัปเดตราคาสด
  3. แตะแถววันนี้ ในตาราง เพื่อเติมกรอบ M30 / H1 ลงฟอร์มอัตโนมัติ ระบบคำนวณระยะวิ่งและ Leverage ให้
  4. ดูสัญญาณเบรก ระบบบอกว่าแท่ง M30 ปิดนอกกรอบฝั่งไหน แตะ Long / Short เพื่อเลือก Position
  5. ใส่ราคาเข้า แล้วกดบันทึก ไม้ขึ้นในรายการทันที ระบบบันทึกให้เบื้องหลัง
  6. ปิดไม้ ใส่ Balance หลังปิด (แตะช่อง Balance ในประวัติการเทรดได้เลย) ระบบคิด % และ Win / Loss ให้

พอร์ต

เมนูล่าง "พอร์ต" · แยกทุน ผลงาน และเส้นที่วาดของแต่ละพอร์ตออกจากกัน

หลายพอร์ตในบัญชีเดียว

  • เพิ่มพอร์ตใหม่: ตั้งชื่อ + ทุนเริ่มต้น
  • เปลี่ยนชื่อ / ลบพอร์ตได้ (ลบต้องพิมพ์ชื่อยืนยัน)
  • แชร์พอร์ตให้บัญชีอื่นได้ (ดูอย่างเดียว / แก้ไขได้) จากเมนูโปรไฟล์มุมขวาบน

การ์ดสรุปพอร์ต

  • Balance, ผลตอบแทน %, จำนวนไม้, Win rate
  • พอร์ตที่ใช้งานอยู่มีขอบสีส้ม
  • สลับพอร์ตเร็วจากปุ่มชื่อพอร์ตที่หัวเว็บ อยู่หน้าเดิมได้เลย

ภาพรวมของพอร์ตที่เลือก

  • เดือนนี้: จำนวนไม้ (และที่ยังเปิดอยู่), Win rate, กำไร / ขาดทุน, ผลตอบแทน
  • Equity: กราฟ Balance ทุกไม้ เส้นเขียวเมื่อกำไร แดงเมื่อขาดทุน ชี้หรือแตะเพื่อดูรายละเอียดแต่ละไม้
  • ไม้ล่าสุด 5 ไม้: แตะเพื่อเปิดกราฟของไม้นั้น

กราฟ

ด้านบนของหน้า "บันทึกไม้" · BTC / USDT เวลาไทย

ราคาสด

  • เลือก Binance (ค่าเริ่มต้น) หรือ MEXC
  • TF 5m · 15m · 30m · 1h
  • แท่งล่าสุดอัปเดตสด (● Live)
  • ส่วนต่างราคา MEXC − Binance แบบสด

กรอบบนกราฟ

  • แถบสี M30 และ H1 ของแต่ละวัน พร้อมเส้นกรอบบน / ล่าง
  • เส้นแบ่งวันเวลา 07:00
  • Reset หรือดับเบิลคลิกที่ว่างบนกราฟ = กลับมุมมองเริ่มต้น

เครื่องมือวาด

  • Crosshair (แตะซ้ำ = โหมดเล็งแบบ MT5), เส้นแนวนอน, เส้นเทรนด์, กล่อง, วัดระยะ (Δ ราคา / % / จำนวนแท่ง), ย้อนกลับ, ลบ
  • เลือกเส้นด้วยดับเบิลคลิก (iPad / มือถือ: แตะสองครั้ง) แล้วจึงลากย้ายหรือปรับปลายเส้นได้ กันเลื่อนเส้นโดยไม่ตั้งใจ
  • เส้นที่วาดเก็บแยกตามพอร์ตในบัญชีของคุณ เปิดจากเครื่องไหนก็เห็นเหมือนกัน

บันทึกไม้

เมนูล่าง "บันทึกไม้"

กรอบราคาจากตลาด

  • กรอบ M30 / H1 ของวันนี้ หรือ 3 วันล่าสุด พร้อมระยะวิ่ง
  • เวลาเริ่ม 20:30 (ช่วง Daylight Saving) หรือ 21:30 (หน้าหนาว)
  • สถานะสด: ยังไม่ถึงเวลา / กำลังก่อตัว (นับถอยหลัง) / ครบ
  • แตะแถว = เติมกรอบลงฟอร์ม

ข้อมูลไม้

  • วันที่, Risk %, Bias ของวัน (Long / Short)
  • ทุน เติมจาก Balance ไม้ก่อนหน้าให้อัตโนมัติ แก้เองได้ถ้าทุนไม้นี้ต่างออกไป

กรอบราคา M30 H1

  • กรอบบน / ล่าง ของแต่ละ TF
  • คำนวณระยะวิ่ง
  • Leverage Long และ Short ตาม Risk % ให้ทันที

การเข้าไม้

  • ตรวจแท่ง M30 ที่ปิดนอกกรอบให้อัตโนมัติ (Breakout)
  • Auto (ตามแผน) หรือ Manual, เลือก Position และ TF
  • วิธีเข้า: เบรก + รีเทส (แบ่ง 2 ไม้) หรือรีเทส 100%
  • คำนวณราคาเฉลี่ย, TP, SL, ราคา Liq. ให้ · Leverage เติมค่าที่คำนวณไว้ แก้เองได้

บันทึกทันที

กดบันทึกแล้วไม้ขึ้นในรายการทันที ฟอร์มว่างพร้อมบันทึกไม้ถัดไป ระบบบันทึกเบื้องหลัง (ระหว่างนั้นแถวจะขึ้น "กำลังบันทึก…") ถ้าส่งไม่สำเร็จ ข้อมูลจะกลับเข้าฟอร์มให้กดบันทึกใหม่ ไม่หาย

ประวัติการเทรด

เมนูล่าง "ประวัติการเทรด"

รายการไม้ทั้งหมด

  • กรองตามผล (Win / Loss / ยังไม่ปิด), TF, Position
  • ไม้ที่ยังไม่ปิด ระบบเช็กจากกราฟว่าชน TP หรือ SL แล้วหรือยัง แล้วแสดงผลให้อัตโนมัติ

แก้ไขด่วน

  • แตะ ราคาเข้า หรือ Balance ในตาราง เพื่อแก้ในหน้าต่างเล็ก เห็นผลลัพธ์ (TP / SL, กำไร / ขาดทุน, Win / Loss) ก่อนบันทึก
  • ปุ่ม "แก้ไข" สำหรับแก้ทุกช่อง · "ลบ" มีหน้าต่างยืนยัน

ดูกราฟของไม้

  • ซูมไปช่วงของไม้นั้นให้เอง พร้อมพื้นที่ TP (เขียว) / SL (แดง) แบบ TradingView และเส้นประจากจุดเข้าไปจุดออก
  • ป้ายราคา #เลขไม้, TP, SL อยู่ที่ต้นเส้น หน้าต่างนี้ไม่มีเครื่องมือวาดหรือราคาสด ให้ดูไม้ได้ชัด ๆ

สรุปผล

เมนูล่าง "สรุปผล" · เลือกช่วง: ทั้งหมด, 7 วัน, 30 วัน, เดือนนี้, เดือนที่แล้ว หรือเลือกวันเอง

ตัวเลขสำคัญ

ทุน / Balanceต้นช่วง และปลายช่วง
ผลงานกำไร / ขาดทุนสุทธิ, ผลตอบแทน %
ความแม่นWin rate, Profit factor
เฉลี่ย% เฉลี่ยไม้ชนะ และไม้แพ้
ความเสี่ยงMax drawdown, ชนะ / แพ้ติดกันสูงสุด

กราฟและตารางแยกผล

  • Equity curve ชี้หรือแตะดูแต่ละไม้ได้
  • แยกตาม TF (M30 / H1), Position (Long / Short), Auto / Manual
  • แยกตาม Bias: เข้าตาม Bias vs เข้าสวน Bias ได้ผลต่างกันแค่ไหน

อื่น ๆ

ความเร็ว การติดตั้ง และความปลอดภัยของข้อมูล

เปิดเร็ว ใช้ต่อเนื่อง

  • จำข้อมูลล่าสุดไว้ในเครื่อง เปิดหน้าแล้วเห็นทันที ระหว่างอัปเดตข้อมูลล่าสุด ไอคอนรีเฟรชที่หัวเว็บจะหมุน
  • ปุ่มรีเฟรชหรือแตะโลโก้ = โหลดหน้าใหม่ทั้งหมด
  • เพิ่มไปยังหน้าจอโฮม (iPhone / Android) ใช้เหมือนแอป

ข้อมูลปลอดภัย

  • เข้าสู่ระบบด้วยอีเมล + รหัสผ่าน · บัญชีใหม่ต้องรอผู้ดูแลอนุมัติก่อนใช้งาน
  • แต่ละบัญชีเห็นเฉพาะพอร์ตของตัวเอง และพอร์ตที่มีคนแชร์ให้
  • กันการแก้หรือลบไม้ผิดไม้ และกันการบันทึกซ้ำเมื่อเน็ตหลุดระหว่างบันทึก
  • ดาวน์โหลดข้อมูลทุกพอร์ตเป็น Excel / CSV ได้จากเมนูโปรไฟล์

ลบพอร์ตแล้วกู้คืนไม่ได้ — ดาวน์โหลดข้อมูลเก็บไว้เป็นระยะ (เมนูโปรไฟล์ → ดาวน์โหลดข้อมูล)
